# ECOMMERCE

A simple e-commerce web application built with Node.js, Express, EJS, and static frontend assets.

## Features

- Product listing page
- Product detail page
- Shopping cart page
- Checkout flow
- Success/confirmation page

## Tech Stack

- Node.js
- Express
- EJS
- HTML/CSS/JavaScript

## Project Structure

```text
.
|-- server.js
|-- package.json
|-- public/
|   |-- css/
|   |-- images/
|   `-- js/
`-- views/
    |-- index.ejs
    |-- product.ejs
    |-- cart.ejs
    |-- checkout.ejs
    `-- success.ejs
```

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the application

```bash
node server.js
```

### 3. Open in browser

Visit:

```text
http://localhost:3000
```
